Cost $1.12 for all pages; median 94.9 s per page (problems on a page run in parallel).

**Honest reading:** on clean pages Muse Spark alone already judges right/wrong very well; the one-call baseline also scored 40/40. What the pipeline adds is that every mark is *proved* by sympy rather than asserted, the first wrong working step is located and circled on the photo, the misconception is diagnosed against the NCERT concept graph, unreadable or incomplete problems go to the teacher instead of being guessed, and text on the page cannot change a grade. Run history: the previous run marked one correct answer wrong (a tight zoom crop clipped the 0 off "60" and two crops outvoted the full-page read); the tie-break read now uses a much wider crop, and this run has no false marks (`results/grading_run4.json` kept for reference).

Ambiguous case: `85 - 46`: subtrahend not drawn: only 85 and 39 visible → the right outcome is needs_review. Pipeline: **needs_review**, baseline: missed.

## 3. Root-cause agent (Muse Wonder)

10 simulated children with a hidden gap concept (`scripts/seed_demo.py`). Neither method sees the hidden gap.

| | Exact root | Within 1 prerequisite hop |
|---|---|---|
| Muse Wonder agent | 2/10 | 2/10 |
| Knowledge-tracing baseline | 0/10 | 1/10 |

Cost $0.76 total, median 22 s per child.

**Two runs, honestly reported.** The run above uses today's demo data: every simulated child is in Class 5 with about 12 past answers spread over ~15 class-level topics, i.e. less than one observation per topic, and the hidden gap often sits below anything that was tested. Evidence that thin is hard for any method; the agent still beats the statistical baseline. An earlier run on mixed Classes 3-5 (denser evidence per topic) scored agent 4/10 exact and 6/10 within one hop, against the baseline's 3/10 and 3/10 (or 6/10 and 8/10 with a lenient single-observation rule) (`results/agent_run4.log`, `agent_run3.log`).

**What this means:** root-causing from a few homework answers is genuinely uncertain, which is why the agent reports a confidence, names an alternative hypothesis, and writes sympy-verified probe questions: a two-minute check with the child collects exactly the evidence that is missing. The agent's value is that reasoning and the probes, not a guaranteed answer. Version history: v1 (about 20 small tool calls, server-side conversation state) failed on 4/10 children; v2 (compact evidence in context, one subgraph tool, client-side state, forced submission) completes every run with 6-7 tool calls.
